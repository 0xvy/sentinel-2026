### Quantitative Facts & Adapter Specifications
- **Abstract Adapter Contract (`backend/adapters/base.py`):**
  - Standardizes lifecycle: `connect()`, `disconnect()`, `normalize_event()`, and `poll_events()`.
  - Non-blocking async execution ensuring vendor latency never stalls the central ingestion loop.
- **Milestone XProtect Adapter (`backend/adapters/milestone.py`):**
  - Parses SOAP envelope XML payload; extracts `EventHeader/ID`, device hardware Presentation Timestamps, and device GUID mapping to GIS coordinates.

  - Normalizes proprietary integer confidence: $c_{\text{norm}} = \text{float}(96.5) / 100.0 = 0.9650$.
  - Cleans hyphenated/spaced strings via regex: `re.sub(r"[^A-Za-z0-9]", "", "GJ-01-ER-8842").upper()` $\rightarrow$ `GJ01ER8842`.
- **Generic ONVIF Adapter (`backend/adapters/onvif_nvr.py`):**
  - Ingests Profile T (Analytics) and Profile M (Metadata) WS-Notification events from Dahua, Hikvision, CP Plus, and Uniview edge NVR appliances.
